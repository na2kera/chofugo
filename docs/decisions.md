# 超富豪 — 設計決定の記録

> 2026-11-16 の仕様確認（Q1〜Q41）で合意した内容。`spec_v0.1.md` の [暫定]・[提案]・[未確定] のうち、ここに書かれた項目は **この文書が優先**する。
> 「合意」はユーザーが明示的に決めたもの、「補完」は設計担当が矛盾を避けるために置いた決まり（仕様書 §13-8 に基づく仮定）。補完は遊んでみて見直してよい。 設計レビューで見つかった未定義の場面は §14 にまとめて決めてある。本文と §14 が食い違う場合は §14 を優先する。

## 0. 用語

| 用語 | 意味 |
|---|---|
| ゲーム | カードを配ってから全員の順位が決まるまでの1回 |
| 試合 | 決めた回数のゲームのまとまり。得点を合計する |
| 場 | いま出ているカード。流れると空になる |
| 親 | 場が空のときに最初に出す人 |
| 組 | 同じ数字のカード1枚以上（1枚出し・2枚組・3枚組・4枚組…） |
| 階段 | 同じマークで数字が連続する3枚以上 |
| 強さの向き | 通常か逆か。革命と J バックで決まる |

## 1. 遊ぶ前提（合意）

- **人数**：4人固定。空席は弱い CPU が埋める（Q1）。
- **端末**：スマホ縦持ちを基準にする。PC では同じ縦長の画面を中央に表示する（Q2）。
- **参加方法**：ホストがルームを作ると、ルーム ID 入りの URL ができる。開いた人は名前を入れるだけで参加する。アカウントはない（Q3）。
- **本人の識別**：端末のブラウザに識別用の秘密の値を保存し、再読み込みや切断のあとも同じ席に戻れる。ブラウザのデータを消すと戻れない（Q3）。
- **席順**：参加した順で固定。階級による席替えはしない（補完）。

## 2. カードと基本の進行

### 2.1 カード（合意）

- 52枚＋ジョーカー2枚の54枚。
- 通常の強さは `3 < 4 < … < K < A < 2`。ジョーカーの1枚出しは、強さの向きに関係なく最強（Q5、Q29）。
- **ジョーカーは代わりに使える**（Q5）。
  - 組に混ぜられる（「7・7・ジョーカー」は7の3枚組）。
  - 階段の足りない数字の代わりになる（階段が ON のとき）。
  - ジョーカー2枚だけの組も出せる。2枚組として最強で、何にも負けない（補完）。
  - 5枚以上の同じ数字の組（4枚＋ジョーカー）も出せる（補完）。

### 2.2 配り方（合意）

- 14枚・14枚・13枚・13枚。14枚になる2人は毎ゲームランダム（Q8）。

### 2.3 手番と場（合意）

- 親が出し、次の人は「同じ種類・同じ枚数で、より強いもの」を出すかパスする。種類は、組（枚数ごと）と階段（枚数ごと）。
- **パスしたら、その場が流れるまで出せない**（Q7）。
- **場が流れる条件**：誰も出さないまま、最後に出した人へ手番が戻ったとき（Q20）。スキップで全員を飛ばして戻った場合も同じ。流れたら、最後に出した人が親になる。
- 親になるはずの人がすでに上がっている場合は、進行方向で次の、まだ上がっていない人が親になる（補完）。
- 場に出たカードの履歴は、全員がログで見られる（補完）。

### 2.4 親が出せるカードを持たないとき（補完）

独裁などで、親が出せる手を1つも持たないことがある。

- 親は、**出せる手が1つもないときだけ**パスできる。
- そのパスで場は流れた扱いになり（独裁などの「場が流れるまで」の効果が切れる）、進行方向で次の人が親になる。

### 2.5 誰も返せないことが全員に分かる場合（補完）

- ジョーカーの1枚出しに対して、返す手段がルール上存在しないとき（スペ3返しが OFF、または「返しの一周」が省かれる条件のとき）は、パスを待たずにすぐ場を流す。

### 2.6 最初に出す人（合意）

- **ダイヤの3スタート OFF**：初回はランダムな人。2ゲーム目以降は前のゲームの大貧民（Q6）。
- **ダイヤの3スタート ON**：毎ゲーム、ダイヤの3を持つ人（Q6）。詳細は §6.11。

## 3. 階級・カード交換・得点

### 3.1 階級（合意）

1位 大富豪、2位 富豪、3位 貧民、4位 大貧民。初回のゲームには階級がない。

### 3.2 カード交換（合意）

- 2ゲーム目以降、配ったあとに行う。大貧民 → 大富豪は最も強い2枚、貧民 → 富豪は最も強い1枚。上位からは好きな枚数ぶん（2枚・1枚）を返す。
- **下位が渡すカード**（Q9）：通常時の強さ（ジョーカー ＞ 2 ＞ A ＞ … ＞ 3）で自動的に選ぶ。同じ強さのカードが複数あって決まらないときだけ、本人がどれを渡すか選ぶ。CPU はランダムに選ぶ。
- **上位が渡すカード**（Q10）：下位のカードを受け取り、それを含めた手札を見てから選ぶ。受け取ったカードをそのまま返してもよい。
- 大富豪と大貧民の組、富豪と貧民の組は並行して進める。
- 渡したカードの中身は、渡した人と受け取った人にだけ見える。
- CPU が上位のときは、通常時の強さでいちばん弱いカードを渡す（補完）。

### 3.3 得点と試合の区切り（合意、Q37）

- 毎ゲーム、大富豪 +2、富豪 +1、貧民 −1、大貧民 −2 を加算する。
- ゲーム数は、ホストが開始前に「5（初期値）・10・無制限」から選ぶ。3モード共通。
- 決めたゲーム数が終わると、合計点で総合順位を発表する。無制限のときは、ホストが「終了」を押した時点で発表する。
- 「同じメンバーでもう一度」で、点数と階級をリセットして続けられる。
- 合計点が同じ人は同じ順位にする（補完）。

## 4. 都落ちと強制最下位

### 4.1 都落ち（合意、Q11）

- 前のゲームの大富豪以外の誰かが **1位に確定した瞬間**、前の大富豪は最下位（大貧民）に決まる。
- その人はその場でゲームから抜ける。残りの手札は捨て札になり、**全員に公開する**（公開は補完）。
- 残った人で2位と3位を決める。
- 超富豪モードでは必須。大富豪モード・カスタムモードでは ON/OFF できる。

### 4.2 最下位が重なったとき（合意、Q31）

- 都落ちと反則上がりなどで強制最下位が2人出た場合、**先に確定した人が4位、あとの人が3位**になる。
- 反則上がりは1位ではないので、それだけでは都落ちの引き金にならない（補完）。

## 5. 超富豪モードの特権

### 5.1 枠の数（仕様書 §4 で確定済み）

- 初めて大富豪になった次のゲームは1個。
- 連覇したときは、1位で上がった瞬間の他3人の残り手札の合計で決める。0〜14枚で1個、15〜24枚で2個、25枚以上で3個。閾値は暫定値で、設定値として持つ。
- 残り手札は、上がった手の効果（7渡し・10捨てなど）を処理し終えたあとの枚数で数える。
- 都落ちしたら0個。未使用の特権は持ち越さない。

### 5.2 共通の決まり（合意）

- **選ぶタイミング**：カード交換が終わったあと、最終的な手札を見てから選ぶ（Q12）。選んでいる間、ほかの人には「大富豪が特権を選んでいる（N個）」とだけ表示する。
- **手番との関係**：特権を使っても手番は終わらない。同じ手番に複数の特権を続けて使える。使ったあとは、カードを出すかパスして手番を終える（Q13）。
- **使える時点**：スキップ以外は「自分の手番の、カードを出す前」。スキップはカードを出すときに付ける。
- 選んだ特権の種類は本人にだけ見える。使った瞬間に全員へ公開する。
- 1種類につき1ゲーム1回。同じ種類は2個持てない。

### 5.3 透視（合意、Q14）

- 相手1人を選び、その手札からランダムに3枚を見る（3枚未満なら全部）。
- 全員に「大富豪が◯◯に透視を使った」と表示する。
- **対象の本人には、どの3枚を見られたかが分かる**。ほかの2人には分からない。
- 大富豪の画面には、見た3枚を、そのカードが出されるかゲームが終わるまで表示し続ける。

### 5.4 強奪（合意、Q15）

- 自分の好きなカード1枚と、相手1人のランダムな1枚を交換する。
- 自分の手番のカードを出す前ならいつでも使える。
- 全員に「大富豪が◯◯に強奪を使った」と表示する。交換された2枚の中身は、当事者2人だけに見える。

### 5.5 強制流し（合意、Q16）

- 自分の手番で、場にカードが出ているときだけ使える。他人の手番への割り込みはできない。
- その場ですでにパスしていると手番が来ないので、使えない。
- ふつうに場が流れたときと同じ扱い。縛り・J バック・パス状態などが解除される。革命は残る。
- 流したあと、大富豪が親になる。

### 5.6 独裁（合意、Q17・Q18）

- 数字を1つ指定し、次に場が流れるまで、全員（自分も含む）その数字を出せなくする。
- 自分の手番のカードを出す前ならいつでも使える（親のときも、場の途中でも）。
- 指定できるのは 3〜2 の13種類。**ジョーカーは指定できない**。ジョーカーの1枚出しは独裁中でも出せる。
- 封じた数字を含む組は出せない（ジョーカーをその数字の代わりにした組も出せない）。封じた数字を含む階段も出せない。
- ダイヤの3スタートの「ダイヤの3を出す義務」が残っている間は、3を指定できない（補完）。

### 5.7 革命（特権）（合意、Q19）

- 自分の手番のカードを出す前に使える。場の途中で使うと、その瞬間から強さが逆になる。
- 効果は4枚組の革命とまったく同じ。ゲームが終わるまで続き、誰かが革命を起こせば元に戻る。
- すでに革命中のときに使うと、通常の強さに戻る。

### 5.8 スキップ（合意、Q20）

- カードを出すときに「スキップを付けて出す」を選ぶ。
- 飛ばす相手は「次に手番が回るはずだった人」。上がった人、その場でパス済みの人は対象にならない。
- 飛ばされた人はパス扱いにならない。
- 出したカードで場が流れる場合や、その1手で自分が上がる場合は使えない。
- 飛ばした結果、誰も出さないまま自分に手番が戻ったら、場が流れて自分が親になる。
- K スキップと重ねると、飛ばす人数を足す（Q34）。

### 5.9 CPU の特権（合意、Q4・Q21）

- CPU が大富豪になったら、枠数ぶんをランダムに選ぶ。透視は選ばない。
- **強奪**：最初の自分の手番で使う。いちばん弱いカードを、ランダムな相手1人と交換する。
- **強制流し**：自分の手番で、場に出せるカードが1枚もないときに使う。
- **独裁**：自分が親になった最初の機会に使い、その時点でいちばん強い数字を封じる。
- **革命**：最初の自分の手番に、手札の半分以上が8より弱いカードなら使う。他人に革命を起こされたら、次の自分の手番で使って戻す。
- **スキップ**：手札が残り3枚以下になったあと、最初にカードを出すときに付ける。
- 数字（3枚以下、半分以上）は仮の値。

### 6.0.1 数字の効果が発動する条件（合意、Q28）

- 同じ数字の組（1枚出しを含む）で出したときに発動する。
- ジョーカーを代わりに混ぜた組でも発動する。枚数で効果が変わるルールでは、ジョーカーもその数字の1枚として数える。
- 階段に含まれているだけでは発動しない。
- ジョーカーの1枚出しでは、どの数字の効果も起きない。
- 同じ数字の4枚組で革命と数字の効果が重なるときは、革命を先に処理する（補完）。

### 6.1 8切り

- 8の組を出すと場が流れ、出した人が親になる。
- 4止めが ON のときは、流れる前に「返しの一周」を行う（§6.2）。

### 6.2 4止め と「返しの一周」（合意、Q24・Q25）

**返しの一周（4止めとスペ3返しに共通）**

- 8切りが起きたとき（4止めが ON）と、ジョーカーが1枚で出されたとき（スペ3返しが ON）に入る。
- 出した人の次の人から順番に、まだ上がっていない全員が「返す」か「スキップ」を選ぶ。**その場ですでにパスした人も参加できる**。
- 返せるカードを持っていない人も、スキップを押す（手札の情報を漏らさないため）。
- 誰かが返した時点で終わる。全員がスキップして出した人に戻ったら不成立。
- CPU は、返せるカードを持っていれば必ず返す。
- **省く条件**（全員に見えている情報だけで判断する）：スペードの3がすでに捨て札にあるときは、スペ3返しの一周を行わない。4がすでに3枚以上捨て札にあるときは、4止めの一周を行わない。

**4止め**

- 8切りが ON のときだけ選べる。8切りを OFF にすると4止めも OFF になる。
- 返すのは本物の4の2枚組。8が何枚出されていても2枚。ジョーカーは代わりにできない。
- 成立すると8切りが無効になる。4の2枚は捨て札になり、8はふつうのカードとして場に残る。手番は、8を出した人の次の人からふつうに続く（パスの状態もそのまま）。
- 不成立なら、ふつうに8切りで場が流れる。

### 6.3 革命（合意、Q29）

- 同じ数字の4枚以上の組、または4枚以上の階段を出すと起きる。ジョーカーを含んでいてもよい。
- 出した瞬間から強さが逆になり、ゲームが終わるまで続く。次のゲームには持ち越さない。
- 革命中にもう一度革命が起きると、元に戻る。

### 6.4 J バック（合意、Q29）

- J の組を出すと、その場が流れるまで強さが逆になる。
- J バック中にもう一度 J が出ても、何も変わらない。
- **強さの向き**は「革命中かどうか」と「J バック中かどうか」を別々に持ち、片方だけなら逆、両方なら通常とする。

### 6.5 スペ3返し（合意、Q25）

- ジョーカーが1枚で出されたとき、「返しの一周」（§6.2）を行う。
- スペードの3を1枚出すと場が流れ、出した人が親になる。
- 不成立なら、ジョーカーを出した人が場を取って親になる。
- スペードの3で上がっても反則にならない。

### 6.6 縛り（マーク縛り）（合意、Q30）

- 場のカードと同じマークのカードが続けて出されたら成立する。その場が流れるまで、そのマークしか出せない。
- 組の場合は、マークの組み合わせが完全に同じときに成立する（「♠・♥」の上に「♠・♥」）。
- 階段の場合は、同じマークの階段が続いたら成立する。
- ジョーカーは、縛り中でも足りないマークの代わりとして出せる（1枚出しも出せる）。**ジョーカーを含む出し方では、縛りは新しく成立しない**。
- 場が流れたら解除される。

### 6.7 激縛り（合意、Q30 への追加）

- マーク縛りとは別に ON/OFF できる。
- 場のカードと同じマークで、強さが1つ上のカードが出されたら成立する（♥6 の上に ♥7）。組の場合は、マークの組み合わせが同じで数字が1つ上のとき。
- その場が流れるまで、同じマークで、直前のカードよりちょうど1つ強いカードしか出せない。
- 「1つ強い」は、その時点の強さの向きで判定する。
- ジョーカーは必要なカードの代わりとして出せ、その数字として扱って連番を続ける。

### 6.8 階段（合意、Q27）

- 同じマークで数字が連続する3枚以上。枚数の上限はない。
- 並びは 3 → 4 → … → K → A → 2。2をまたぐ並びは作れない。
- ジョーカーは足りない数字の代わりに使える。端に置く場合は、出せる解釈のうちその時点でいちばん強くなる位置として扱う（補完）。
- 場が階段のときは、同じ枚数の階段だけ出せる。**出す階段のいちばん弱いカードが、場の階段のいちばん強いカードより強い**こと。
- 場の階段と違うマークでもよい（縛りが成立しているときを除く）。
- 強さが逆のときは、判定も逆になる。

### 6.9 禁止上がり（合意、Q31）

- 最後の1手が次のどれかだと反則になる。
  - ジョーカーを含む手（1枚出し、組、階段のどれでも）
  - その時点でいちばん強い数字の組（通常は2、強さが逆のときは3）
  - 8の組（8切りが ON のとき）
- 階段の途中に8や2が含まれているだけなら反則にならない。
- 7渡し・10捨てで最後のカードを手放して上がるのは反則にならない。
- 反則で上がった人は、その場で最下位が確定する（§4.2）。
- 反則になる手は出せないようにはしない。出そうとすると確認を出す。

### 6.11 ダイヤの3スタート（合意、Q6・Q26）

- ON なら毎ゲーム、ダイヤの3を持つ人から始める。
- **最初の1手には必ずダイヤの3を含める**。1枚で出しても、組や階段に含めてもよい。
- 最初の1手だけ、ダイヤの3を含む出し方しか選べないようにし、理由を表示する。

### 6.12 砂嵐（合意、Q32）

- 本物の3が3枚。ジョーカーを3の代わりにはできない。3の4枚組は砂嵐ではなく革命。
- 自分の手番なら、場が何であっても出せる。マーク縛りと激縛りも無視できる。
- 出すとすぐに場が流れ、出した人が親になる。場が空のときに出しても同じ。
- 強さの向きに関係なく、何にでも勝つ。
- 独裁で3が封じられている間は出せない。
- 砂嵐で上がっても反則にならない。

### 6.13 7渡し・10捨て（合意、Q33）

- **7渡し**：7の組を出したあと、出した枚数まで、手札から好きなカードを次の人に渡せる。渡さなくてもよい。相手は進行方向で次の、まだ上がっていない人（パス済みでもよい）。中身は当事者だけに見える。
- **10捨て**：10の組を出したあと、出した枚数まで、手札から好きなカードを捨てられる。捨てなくてもよい。捨てたカードは全員に見える。
- 渡す・捨てることで手札が0枚になったら上がり。反則にならない。
- 順番は「カードを出す → 渡す・捨てる → 上がりの判定 → 次の人の手番」。場は流れない。
- CPU は、いちばん弱いカードから上限まで手放す。

### 6.14 9リバース（合意、Q34）

- 9の組を出すと、その場が流れるまで手番の順が逆回りになる。何枚出しても同じ。場が流れると元に戻る。
- 9を出した直後から逆回り。
- 逆回り中にもう一度9が出ても、何も変わらない。
- 7渡しの相手、スキップで飛ばす相手、返しの一周の順番は、その時点の向きで決める。

### 6.15 K スキップ（合意、Q34）

- K の組を出すと、出した枚数ぶんの人数を必ず飛ばす。
- 飛ばす相手と扱いは特権のスキップ（§5.8）と同じ。
- 全員を飛ばして自分に戻ったら、場が流れて自分が親になる。

## 8. 制限時間（合意、Q38）

| 場面 | 時間 | 時間切れのとき |
|---|---|---|
| 自分の手番 | 30秒 | 自動でパス。親のときは下の決まりで1手を自動で出す |
| 返しの一周 | 10秒 | 自動でスキップ |
| 7渡し・10捨ての選択 | 15秒 | 渡さない・捨てない |
| カード交換 | 60秒 | 下位：同じ強さの候補の中からランダムに渡す。上位：いちばん弱いカードから必要な枚数を渡す |

## 9. 切断と途中参加（合意、Q39）

- 接続が切れて10秒たっても戻らなければ、その人の手番は CPU が代わりに操作する。
- 戻ってきたら、すぐ本人の操作に戻る。手札・点数・階級・特権はそのまま。
- 席は試合が終わるまで確保する。代役の CPU は、その人の特権を §5.9 の決まりで使う。
- ホストが代役に切り替わったら（切断から10秒後）、ホストの権限は、接続中の人間のうち席順で次の人に移る。
- 人間が全員いなくなったら一時停止する。30分以内に誰かが戻れば再開し、戻らなければルームを閉じる。
- ゲームとゲームの間であれば、CPU の席に新しい人が入れる。その席の点数と階級を引き継ぐ。ゲームの途中では入れない。観戦はない。

## 14. 設計レビューを受けて決めたこと（補完、2026-11-16）

Codex の設計レビューで見つかった未定義の場面を、ここで決める。すべて補完（設計担当の判断）で、遊んでみて見直してよい。

### 14.1 場が流れる条件（§2.3 の補足）

- 「最後に出した人の席」を一周の基準にする。**その人が上がったり抜けたりしていても、席の位置を基準に一周を数える**。
- 手番を次へ送るとき、まだゲームに残っていてパスしていない人を進行方向に探す。見つかる前に最後に出した人の席に着いたら、場が流れる。
- 流れたあとの親は、最後に出した人。その人がもう残っていなければ、その席から進行方向で次の、残っている人。

### 14.2 順位の確定（§4 の補足）

- 上がった人は上の順位から、強制最下位は下の順位から埋める。
- **残っている人が1人になったら、その人を空いている順位に確定してゲームを終える**（手札が残っていてもよい）。3人が続けて反則上がりをした場合、残った1人が1位になる。
- 一度順位が確定した人を、もう一度確定させない。すでに順位が確定している前の大富豪は、都落ちの対象にならない。
- 都落ちと反則上がりが重なり、先に反則で4位が出た場合、都落ちした人は3位（貧民）になる。これは Q31 の合意によるもので、仕様書 §4.4 の「都落ち＝大貧民」よりこちらを優先する。この場合も、都落ちした人の特権はすべて消える。

### 14.3 上がりが決まる時点

- 1手の処理は「カードを出す → 自分の手札を動かす効果（7渡し・10捨て） → **上がりの判定** → 返しの一周 → 場の流れ」の順に行う。
- **出した人の上がり（または反則上がり）は、返しの一周より前に確定する**。1位が確定して都落ちが起きる場合も、返しの一周の前に処理する。都落ちで抜けた人は、その返しの一周に参加しない。
- 返しの一周で返した人の手札が0枚になったら、その人もそこで上がる（スペードの3や4の2枚組で上がるのは反則ではない）。
- 例：禁止上がりが OFF で、A が最後の1枚のジョーカーを出し、B が最後の1枚のスペードの3で返した場合、A が先、B が次の順位になる。

### 14.4 禁止上がりの判定と、反則のときの効果（§6.9 の補足）

- 「その時点でいちばん強い数字」は、**その手を出す直前の強さの向き**で決める。通常の状態で最後に2の4枚組を出すと反則。3の4枚組は反則ではない。
- 反則上がりになっても、**その手の効果（8切り、革命、J バックなど）はふつうに起きる**。
- 画面の確認表示（「反則になります」）も、同じ判定を使う。

### 14.5 カード交換の細部（§3.2 の補足）

- 下位の人に選択の余地がないとき（渡すカードが強さだけで決まるとき）は、待たずに自動で渡す。
- 下位の人が時間切れになったら、同じ強さの候補の中からランダムに決める。強さで決まっている分は必ず渡す。
- 上位の人が時間切れになったら、通常時の強さでいちばん弱いカードから必要な枚数を渡す。同じ強さなら、マークの決まった順（スペード、ハート、ダイヤ、クラブ）で選ぶ。
- 60秒は、選択が必要になった時点からそれぞれ数える（下位の選択に60秒、受け取ったあとの上位の選択に60秒）。

### 14.6 ジョーカーの解釈を決める時点

- ジョーカーを含む手は、**出した時点で「どの数字・どのマークの代わりか」を確定して記録する**。あとから革命などで強さの向きが変わっても、解釈は変えない。
- 解釈が複数あり得るとき（階段の端にジョーカーを置く場合など）は、その時点のすべての制限を満たす解釈のうち、その時点の強さの向きでいちばん強くなるものを選ぶ。
- マーク縛りは、**比べる2つの手のどちらかにジョーカーが含まれていれば成立しない**。

### 14.7 返しの一周が無視する制限と守る制限

- スペ3返しと4止めは、**マーク縛り・激縛り・場の種類と枚数・自分のパス状態を無視して**出せる。
- 独裁で封じられた数字は、返しにも使えない（3が封じられていればスペ3返しはできず、4が封じられていれば4止めはできない）。
- 返しの一周に参加するのは、一周が始まる時点でゲームに残っている、出した人以外の全員。

### 14.8 その2で作るルールの補足

- **激縛りは組だけに適用する**。階段には適用しない。
- 激縛り中の1枚出しのジョーカーは、必要な数字の代わりとして扱う。数字の効果も返しの一周も起きない。次の人は、さらに1つ強い数字を出す。
- **K スキップは、上がる手でも出せて、効果も起きる**。「上がる手では使えない」は特権のスキップだけの条件。飛ばす対象は1人につき1回までで、全員を飛ばしたら場が流れる。
- **場が流れるときの順番**：先に「場が流れるまで」の効果（J バック、縛り、9リバース、独裁、パス状態）を解除し、そのあとで親を決める。親を探す向きは、解除後の（元の）向きを使う。
- 砂嵐は、マーク縛り・激縛り・場の種類と枚数を無視するが、独裁は守る。

### 14.9 CPU の選び方（§5.9・設計書の補足）

- 候補の手を、次の順で並べて先頭を選ぶ。(1) 反則上がりにならない手を先に。(2) その手のいちばん弱いカードが、その時点の強さの向きで弱い順。(3) 枚数の多い順。(4) 組を階段より先に。(5) カード ID の並び順。
- 乱数を使うのは、決定の記録で「ランダム」と決めた箇所だけ（下位の交換の選択、特権の選択と対象）。

### 14.10 制限時間の細部（§8 の補足）

- 期限を過ぎていても、時間切れの自動操作が実行される前にサーバーへ届いた本人の操作は受け付ける（先に処理されたほうが有効）。
- 期限が同時に切れた場合は、待ちの番号が小さい順に処理する。
- 特権を使っても手番は続くので、手番の30秒は数え直さない（その3）。

### 14.11 切断の検出と復帰（§9 の補足）

- 切断は、接続が閉じた通知か、**一定時間応答がないこと**で検出する。「10秒」は、切断を検出してから代役に切り替えるまでの猶予。回線が黙って切れた場合は、検出までの時間（約15秒）が加わる。
- 戻ってきた本人の待ちは、秒数いっぱいに付け直す。全員不在から再開した場合、戻ってきた人以外の席の待ちは、止めた時点の残り時間で再開する。
- 接続の状態が変わるたび（接続、切断の検出、代役への切り替え、一時停止からの再開）に、ホストが「接続中の人間」かどうかを確かめ直す。違っていれば、接続中の人間のうち席順で次の人に移す。

### 14.12 試合の終了（§3.3 の補足）

- ホストが試合を終えられるのは、ゲームの結果画面のときだけ。ゲームの途中では終えられない（その1）。

### 14.13 その3を作るときに決めること

- ダイヤの3スタートの最初の1手より前に、強奪でダイヤの3が動いた場合の義務の扱い。
- 特権の対象にできる相手の条件（すでに抜けた人、手札が0枚の人）と、CPU の方針が実行できないときの代わりの動き。
- 透視で見たカードが、そのあと7渡しや強奪で動いたときの表示。

### 14.14 engine の実装レビューを受けて決めたこと（補完、2026-11-16）

- **ジョーカーだけの手はすぐ流す**（§2.5 の拡張）：ジョーカー2枚の組も何にも負けないので、出したらすぐ場を流す。1枚出しは、これまでどおり返しの一周（スペ3返しが ON で、省く条件に当たらないとき）を先に行う。
- **返しの一周を省くかどうかは、一周を始める直前の状態で決める**：出した手で1位が確定して都落ちが起き、都落ちした人の手札にあったスペードの3が捨て札として公開された場合、返しの一周は行わない。
- **CPU の選び方**（§14.9 の差し替え）：候補の手を次の順で並べて先頭を選ぶ。(1) 反則上がりにならない手を先に。(2) **ジョーカーを使わない手を先に。** (3) その手のいちばん弱いカードが、その時点の強さの向きで弱い順。(4) 枚数の多い順。(5) 組を階段より先に。(6) カードの並び順（数字の弱い順、同じ数字ならスペード・ハート・ダイヤ・クラブ、ジョーカーは最後）。時間切れで親が出す手も、反則にならない1枚出しがないときはこの並びを使う。
- **交換でジョーカー2枚のうち1枚を渡す場合**は、どちらを渡しても同じなので、本人に選ばせずに自動で渡す（§3.2 の「同じ強さなら本人が選ぶ」の例外）。
- **組の中のジョーカーのマーク**は、縛りが成立しているときだけ決めて記録する。縛りがないときはマークを決めない（§14.6 の補足。ジョーカーを含む手からは縛りが成立しないので、結果に影響しない）。
- **組にも階段にも読める手**（「♠5・ジョーカー・ジョーカー」など）は、どちらとして出すかをプレイヤーが選ぶ。
- **スペードの3で上がっても反則にならない**のは、返しの一周で返したときだけ。強さが逆のときに、ふつうの手番で最後の1枚としてスペードの3（その時点でいちばん強い数字）を出した場合は、§6.9 のとおり反則になる。
- 回数の決まった試合では、最後のゲームが終わるとそのまま試合の結果に進む。
