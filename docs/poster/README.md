# 紹介ポスター（A4 横、QR コード付き）

開発のときだけの画面 `/dev/poster?v=a`（`b`・`c`・`d`）で4案を描き、PDF と PNG に撮ったもの。
画像生成は使っていない。ゲームの画面と同じ部品（Logo・TitleDeco・Card・Pixel・ドットの枠、d は対戦画面そのもの）を並べている。依存は足していない。

- `poster-<案>.pdf`：刷る用（A4 横、1ページ、余白0、地の色あり）
- `poster-<案>.png`：画面で見る・送る用（2245×1587）

## 作り直し

開発サーバーを起動してから、リポジトリのルートで実行する。

```sh
node packages/client/scripts/poster.mjs http://localhost:19473 docs/poster
```

1ページでない PDF や、フォントが読めていないときはエラーになる。

## 刷るとき

- 「実際のサイズ」（100%）を選び、ヘッダーとフッターは付けない。
- 家庭用のプリンターは端まで刷れないので、暗い地の案（a・b・d）は白いふちが出る。c は明るい地なので、ふちが目立たず、インクも少ない。
- 大事なもの（文字・QR）は、紙の端から 64px（約17mm）以上内側に置いてある。

## 4案

どの案にも、ロゴ、`4人で遊ぶ オンライン大富豪`、QR、`ここから遊べる`、`chofugo.na2kera.com` を載せている。

- **a**：暗い地。左にタイトル画面の飾り（マーク・ロゴ・見出し・トランプ3枚）を2倍で、右に QR。下に細い線を引いて、特長3つを1行に並べる。モードの紹介はなし。
- **b**：暗い地。左上にロゴ、その右に見出し。中央左に3倍のトランプ4枚、右に QR。特長は `リンクを送って 友だちと対戦` だけ。
- **c**：明るい地（`--cream`）。左上にロゴと見出し、右上に小さなトランプ3枚。線の下、左に3つのモードの名前と1行、右に QR。特長はなし。
- **d**：暗い地。左に対戦画面（超富豪モードの自分の番。390×800 を 0.75 倍）、右にロゴ・見出し・特長3つ・QR。

## 載せた文

- 見出し：`4人で遊ぶ オンライン大富豪`
- 特長：`スマホのブラウザで すぐ遊べる`／`インストールも 登録も いらない`／`リンクを送って 友だちと対戦`
- モード：`大富豪`（`おなじみのルールで`）／`カスタム`（`24種のルールを 好きに組み合わせ`）／`超富豪`（`1位になると 特権が使える`）
- QR のそば：`ここから遊べる`、`chofugo.na2kera.com`

数字はコードの定義で確かめた（ルールは `ALL_RULE_IDS` が24、特権は次のゲームで1位だった人に付く）。

## QR コード

- 中身は `https://chofugo.na2kera.com`、誤り訂正は Q、29×29 点（`packages/client/src/dev/qr.ts`）。macOS の CoreImage で作った点の並びを写した。URL を変えるときは作り直す。
- 1点は 6px の四角（紙の上で約 1.6mm）、まわりに4点ぶんの明るい余白。全体で 222px 四方（約 59mm）。拡大・縮小はしていない。暗い点は `--ink`、地は `--cream`。
- 4案とも、PNG、PDF を画像にしたもの（幅3508px）、幅800px に縮めた PNG のそれぞれから、macOS の読み取り（Vision）で `https://chofugo.na2kera.com` と読めることを確かめた。

## 確かめていないこと

- 実際に紙に刷ったときの見え方（色、にじみ、白いふち）と、刷った紙をスマホのカメラで読めるか。
